# Butler

Butler is a Kubernetes-as-a-Service platform that provisions and manages tenant Kubernetes clusters across multiple infrastructure providers.

## Project

- **[Governance](GOVERNANCE.md)** — Project governance model
- **[Code of Conduct](CODE_OF_CONDUCT.md)** — Community standards
- **[DCO](DCO.md)** — Developer Certificate of Origin

## Ecosystem

Butler consists of multiple repositories:

| Component | Description |
|-----------|-------------|
| [butler-controller](https://github.com/butlerdotdev/butler-controller) | CRD reconciliation controllers |
| [butler-server](https://github.com/butlerdotdev/butler-server) | HTTP/WS API server |
| [butler-console](https://github.com/butlerdotdev/butler-console) | React SPA frontend |
| [butler-cli](https://github.com/butlerdotdev/butler-cli) | butleradm + butlerctl CLIs |
| [butler-api](https://github.com/butlerdotdev/butler-api) | CRD type definitions |
| [steward](https://github.com/butlerdotdev/steward) | Hosted control plane operator |
| [butler-charts](https://github.com/butlerdotdev/butler-charts) | Helm charts |
